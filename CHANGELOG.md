# Changelog

## 1.0.1

- Plugin ID is now `three-d-model-gallery` (community directory rules: letters and hyphens only).

## 1.0.0

First release.

- 3D viewer block for FBX, glTF / GLB, OBJ, STL, PLY, 3DS, DAE, 3MF and AMF, with soft studio lighting and a transparent or colored background.
- Drop model files into a note from the file manager or Obsidian's file list; referenced textures come along.
- 3D gallery of the model's folder with previews.
- Animation bar: on / off, clip, play / pause, loop, skeleton, bone names.
- Model info: format, quads / tris, animations, skeletons, bones.
- Screenshots: save where you choose or next to the model, copy to the clipboard.
- Each view remembers its model, camera and animation settings.
